# Guilherme Silva — Portfólio

Portfólio multilíngue de Guilherme Silva, desenvolvido para apresentar projetos autorais, soluções digitais, desenvolvimento front-end, QA, dados, automação e IA aplicada.

## Acesso

- **Site publicado:** https://nilofolio-csrdegd3.manus.space/
- **Repositório:** https://github.com/e0guy/portfolio-guilherme-silva

## Destaques

- Interface editorial responsiva inspirada em portfólios profissionais.
- Conteúdo em português, espanhol e inglês com seletor de idioma.
- Cases de ONG/CRM, sites comerciais, produtos SaaS, API REST e Nova Notes.
- Seção de ferramentas com ícones e níveis visuais de proficiência.
- Links para CV, e-mail, LinkedIn, Instagram, WhatsApp e projetos publicados.

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide React e CSS responsivo.

## Executar localmente

```bash
pnpm install
pnpm dev
```

Para validar a versão de produção:

```bash
pnpm check
pnpm build
```
